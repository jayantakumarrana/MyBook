Private BOOK
====================

Open index.html in a modern browser.

Features:
- Premium leather-style cover
- Gold embossed-style decoration
- Deep book spine
- Visible page block
- Two-page open book
- Realistic page turning
- Page curl shadows
- Paper texture
- Animated photographs
- Bookmark
- Background music toggle
- 10 numbered poetry pages
- Thanks page and back cover
- Read Again
- Keyboard arrows

Replace images/page1.svg through page10.svg with your own JPG/PNG images.
For music, put an MP3 named music.mp3 beside index.html.
